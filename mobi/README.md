# Mobi public execution namespace

This directory contains only public-safe, disposable execution harness material for Android platform validation.

It is not the canonical Mobi repository and does not contain private product design, private assets, credentials, signing material, or canonical project history.

Layout:
- `harness/`: generic Android test apps and build configuration
- `tools/`: deterministic execution and verification scripts
- `fixtures/`: public-safe test fixtures only
- `output/`: generated execution reports (not canonical evidence)

Canonical decisions and accepted evidence remain in the private Mobi repository.
