# 등급별 의뢰 난도 v0.26 (2026-11-25)
## 승인 방향
등급과 의뢰 난도 직접 연계. 상위 등급이어도 낮은 의뢰 선택 가능. 개별 퍼즐 난도는 3단계 그대로, 한 단계씩 상승. 기존 발행/수락 의뢰 불변, 입문 12개 시험 및 퍼즐 원본 변경 없음.

비율은 각 퍼즐별 무작위 추출 목표 확률이지 개별 의뢰에서 정확히 고정되는 할당량이 아니다. 미해결 퍼즐은 쉬움, 쉬움 해결 후 보통까지, 보통 해결 후 어려움까지 허용. 기존 보통 이상 해결한 퍼즐 종류 8개 이상 조건 유지(미충족 시 어려움→보통). 어려움 목표 확률은 C부터 적용. 숙련 미달에 따른 하향으로 실제 비율은 달라짐. 생성 단계는 F/E 1, D 이상 2. 배치 여유 있을 때 분기와 추가 경로/복합 목표 확률 적용, 기존 지도 칸 제한 및 연결 유효성 유지. 추적 배율은 의뢰 유형의 기존 속도에 곱함. 제한시간 산식 및 보상/승급 기준 유지.
일반 의뢰 3개: F는 F급만, 그 외에는 신규 발행 시 현재 등급 2개와 2단계 낮은 등급(최소 F) 1개를 목표로 하되 기존 발행본을 강제 교체하지 않는다. 의뢰별 유형 개방도 해당 의뢰 등급 기준. 특수 의뢰는 현재 해커 등급. 기존 의뢰에 등급 데이터가 없으면 '기존' 표시, 기존 네트워크/보수 유지. 최고 난도와 전체 쉬움/보통/어려움 개수는 실제 스냅샷 기준. 개수에는 선택적 경로에 있는 퍼즐도 포함.
