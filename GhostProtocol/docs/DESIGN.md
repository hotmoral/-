# 게임 설계 및 확정 규칙

**최신 퍼즐 UI/설명/제작 기준:** `PUZZLE_DEVELOPMENT_STANDARD.md` 필수 참조. 아래 기존 규칙은 유지하되 최신 승인 내용이 우선하며, 버전별 역사 기록과 현재 정책을 구분한다.
## 핵심
프리랜서 해커가 가상 네트워크의 권한을 확보하며 목표를 달성한다. 모든 해킹은 실제 외부 시스템과 무관한 논리 퍼즐과 로컬 시뮬레이션이다. 활성 24개 독립 게임(기존 내부 ID10 폐기, ID11 탐색 유지), 기존 공통 유형 분류 및 난도 3단계. 정답 자동 생성 및 검증. 시간 제한은 임무 단위이며 개별 퍼즐에 독립 필수 제한을 두지 않는다.
## 퍼즐 목록
01 이상 탐지 / 02 일치 검증 / 03 오류 검출 / 04 동일 데이터 연결 / 05 그룹 분류 / 06 조건 필터링 / 07 패턴 완성 / 08 누락 데이터 복원 / 09 변환 추론 / 10 [폐기: 조합 추론] / 11 인증 코드 탐색 / 12 목표값 조합 / 13 복합 조건 충족 / 14 조건 연쇄 해결 / 15 예외 발견 / 16 비트 스위치 조작 / 17 경로 연결 / 18 경로 복원 / 19 경로 차단 / 20 다중 경로 연결 / 21 데이터 블록 회전 / 22 순서 복원 / 23 실행 순서 구성 / 24 순차 탐색 / 25 분류·순차 정렬.
17 최단 경로, 18 전체 연결 최소 비용, 19 정상망 보존 및 위협 격리 최소 비용, 20 교차 금지 및 모든 비장애물 칸 사용(3/5/7 채널), 21 외부 IN/OUT 및 분기별 식별자, 24 1~16/25/49 순차 선택, 25 채널별 순서 유지(채널 간 교차 처리 가능). 07~09는 반복·위치 이동·치환·간단 수열·복합 기호 규칙 사용. 실제 플레이에는 플레이어가 추론해야 하는 규칙명/반복 주기/방향 등을 직접 제공하지 않는다. 목표와 필수 제약만 표시.
## 설비 및 임무
설비 15종: 로컬 시스템, 게이트웨이, 중계 서버, 방화벽, 인증 서버, 접근 키, 감시, 데이터 서버, 백업, 메일, 통신, CCTV, 제어, 로그, 코어. 미발견 설비 숨김, 선행 열람으로 일반 설비 자동 식별. 특별 은닉 설비에만 식별 퍼즐. 권한 색상 회색(불가), 파랑(가능), 초록(열람), 보라(제어, 열람 포함). 중요도·주의·위험·추적·오프라인은 권한과 별도. 중요 설비는 황색 아이콘/이름과 권한색 테두리. 연결선이 아이콘 안으로 비치지 않게 한다.
임무 유형 12: 정보 획득, 인물 추적, 데이터 복구, 시설 제어, 시스템 무력화, 보호, 감염 제거, 통신 분석, 사건 조사, 네트워크 복구, 네트워크 구축, 침입자 추적. 초기 12 시험에서 설비/퍼즐/상태 최초 등장과 설명을 순차 배치. 1~3개 퍼즐에 4/6/8분 등 여유 있게 시작. 이후 관련 설비별 난도 단계 상승. 일반 임무는 분기/교차/대체 경로.
추적: 입문 무추적, 일반 임무 조건부 또는 즉시 시작. 0~29 정상, 30~59 주의, 60~84 경보 및 임시 링크 단절, 85~99 긴급, 100 실패. 최초 주의 +5%, 위험 +12%, 감시 제어 추적 -25%, 시간 +45초, 추적 속도 -55%, 임시 링크 15초 후 복원. 구현본과 대조 후 변경.
## UI/연출
가로 화면. 좌측 설비 작업, 중앙 네트워크(드래그/핀치/확대/맞춤), 우측 실시간 로컬 JS 처리 터미널. 코드/결과는 상황에 맞게 표현. 임무 목표는 상단 버튼으로 조회, 효과음 토글, 재시작 및 검수 초기화. 팝업/설명/비조작 연출 중 시간·추적 정지. 최초 설명은 유형별 1회, 도움말에서 다시 확인. 최초 퍼즐 설명은 공통 크기 팝업에서 왼쪽 NPC 안내, 오른쪽 실제 UI 기반 단계별 시연, 하단 취소/문제 시작으로 구성. 최초 상황·목적·도구 소개 후 조작→반응→결과→해석. 단계/대사는 사용자가 직접 전환. 중복 텍스트 금지. 최초 상태/설비 설명은 실제 설비를 먼저 강조. 승인된 예시를 보존하고 각 퍼즐 개선 시 최신 공통 기준을 적용. 임무 브리핑 폭 57%, 나머지 팝업 별도 승인된 규격 유지. 지도 입문 노드 중앙 집중, 복잡한 일반망은 충돌 방지. 선택 테두리가 이름 가리지 않도록. 한글 단어 중간 줄바꿈 최소화. 기존 클리어 미니 팝업은 시간 정지 후 복귀. 자체 승인 완료 연출이 있는 퍼즐은 중복 팝업 금지(인증 탐색 1.65초 중앙 잠금 해제). 결과창의 건너뛰기 → 다음 임무/재도전 버튼 동일 위치·크기, 자동으로 다음 임무 진입하지 않음. 글리치: 지진처럼 전체 화면 흔들지 않고 수평 신호 왜곡/노이즈. 터미널 스타일 버튼 통일.
## 검수
과거 보고 기준: 퍼즐 25×3 자동 해결, 패턴 공개 단서 유일성, 지도 24개 임무 및 여러 가로 크기, 설명창 넘침, 실제 삼성 브라우저 사용자 검수 반복. 수치는 과거 보고이며 이번 저장 작업에서 재실행한 것은 아님. 실제 모바일 저장·터치 검수는 별도로 한다.
