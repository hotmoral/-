# v0.29 실제 조작 중심 회귀 검수 (2026-11-25)
## 수정
- 지도 SVG 설비 아이콘 및 명칭 사이 빈 공간의 터치 누락 재현(시험 07 통신 서버). 투명 hit 영역 추가, 시각 디자인 및 좌표/네트워크 규칙 불변.
- 부모 효과음 OFF가 iframe에 전달되지 않던 문제 수정. ON/OFF 전달, 저장 및 초기화 시 설정 유지. 내장 퍼즐 원본 데이터는 변경하지 않고 실행 설정만 전달.
- 해커 기록에 선택적 '검수 기록' JSON 내보내기. 완료/실패한 최근 120개 임무의 종류/의뢰 ID·등급/결과 및 실패 원인/제한·추가·잔여·활성 시간/최대·최종 추적률/감시 제어/중단 모듈 수, 개별 퍼즐 ID·난도·결과·활성 시간·해결 시 보고 시간과 오답을 기기 저장. 중단 퍼즐의 오답 및 보고 시간은 미측정(null). 활성 시간은 게임 타이머 기준(초 단위), 보고 시간은 iframe 측정(일부 연출 대기 포함 가능). 임무를 재시작하거나 중도 이탈하면 아직 완료되지 않은 임무의 측정은 저장하지 않음. 자동 외부 전송 없음. 명시적으로 버튼을 누를 때만 JSON 파일 내보냄. 초기화 시 기록 삭제. 실제 플레이 데이터 확보 후 수치 조정 예정.
## 검수 결과
- Chromium 768×358: 신규 프롤로그 → 시험 12개 모두 순서대로 실제 설비 버튼과 퍼즐의 정답 조작 함수(G.solve, DOM 클릭)로 해결. 25종 모두 실제 완료 메시지 및 권한 처리. ZERO 승인, ECHO 인계, 의뢰 목록, 재실행 시 목록 유지, 첫 일반 의뢰(LUNA 소개 포함) 7개 퍼즐 해결 및 보상 저장, 재실행 후 실적/검수 기록 13건 유지, JS 오류 없음.
- Chromium 640×300: D 등급·명성 100으로 초기 상태를 구성해 첫 특수 의뢰(지워진 기록) 실제 퍼즐 8개 해결, LUNA 중간 통신 및 성공, 일반 목록 보존, 특수 성공 횟수 기록. 검수 기록 JSON 다운로드 및 내용 확인. 일반 의뢰에서 추적률을 100으로 주입하여 실패 및 기록 복원 검사 통과. 프로필 넘침 없음. JS 오류 없음.
- 25종×3난도×3 가로 iframe 크기(768×300,692×255,640×242) = 225회 실제 정답 조작 함수(G.solve, DOM 클릭)로 모두 해결, 오답 0, 가로 넘침 0, JS 오류 0.
- 24개 임무×3 가로 화면(768×358,692×313,640×300)의 모든 설비 표시 상태에서 아이콘과 명칭 사이 지점 hit test 총 384개 통과. 효과음 ON/OFF iframe 전달, 중단 모듈 기록 각 화면 확인.
- 검수는 Chromium이며 실제 스마트폰 실기기 미검수. 브라우저 정책상 로컬 HTTP 접근 차단으로 저장은 모의 localStorage를 사용. G.solve는 생성된 정답을 DOM으로 선택하는 기능 검증이며 실제 사람의 난도/풀이 속도 측정이 아님. 특수 의뢰 나머지 4개 전 과정 및 실제 사용자 밸런스는 후속 검수. 난도/추적/시간/성장 수치는 v0.28 유지.
