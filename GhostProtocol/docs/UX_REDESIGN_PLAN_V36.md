## 기호 기반 시각 언어 (승인 방향, 10/11 실기기 확정 전)
사용자 아이디어: 숫자·위치 일치/숫자만 일치/없는 숫자를 최초 설명에서 기호와 연결하고 이후 개수만 표시. 색상만 의존하지 않고 형태를 함께 사용. 시범안: 초록 체크(숫자와 위치 모두 같음), 주황 양방향 화살표(숫자는 같고 위치 다름), 빨강 X(인증 코드에 없음). 예: 코드 123, 비교 345 → 체크0/화살표1/X2. 비교 숫자 중복 금지인 기존 규칙 유지. 세 번째 개수는 길이−정확−위치 다름이며 기존 단서 외 정보 추가 없음. 실제 문제에서 어떤 숫자나 위치가 일치하는지 절대 공개하지 않음. 설명 전용 예시만 대응 위치 표시. 기호 의미 재확인 가능. 정답 공개 없는 공통 기호: 체크 정상/충족, X 오류, 양방향 화살표 위치 변경, 파랑 표적 선택/작업 가능, 잠금/해제, 회전, 연결/차단, 주의. 기호의 세부 외형은 실기기 승인 이후 확정.
## 설명 및 플레이
실제 플레이 UI와 동일한 요소/배치로 예시를 제작(별도 정지 도식과 불일치 금지). 목표→단서/기호 이해→조작 시연→완료. 각 단계의 짧은 애니메이션 자동 재생 후 정지. 이전/다음/현재 다시 보기/건너뛰기, 마지막 작업 시작. 진행 속도는 사용자가 결정, 도움말에서 동일 시연 재확인, 시간/추적 정지. 별도 속도 설정은 우선 추가하지 않음. NPC 말투 유지. 화면 채우기 목적의 강제 좌우 분할 금지. 정보 중요도와 시선 흐름에 따라 퍼즐별 배치. 조작 반응 중심의 스캔·인증·복구·신호 흐름·조건 상태 변화를 사용하되 과도한 반복 대기 금지.
