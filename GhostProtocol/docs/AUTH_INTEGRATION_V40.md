# v0.40 인증 코드 탐색 R6 통합 및 추론 폐기 (2026-11-26)
## 확정 사항
사용자 실기기 승인: 독립 Ghost_Protocol_AUTH_Discovery_R6.html의 탐색 디자인/연출/6단계 설명을 정식 채택. 인증 코드 추론(ID 10)은 폐기, 인증 코드 탐색(ID 11) C형(초기 기록 0)만 유지. 활성 퍼즐 24종. 다른 23종의 기존 생성/판정/렌더링은 유지한다. 디자인 제안과 검수는 가로 우선.
## 통합
- v0.39에서 v0.40으로 변경. R6를 별도 AUTH_DATA 내장 문서로 이식, 임무가 지정한 난도 및 토큰을 전달. 독립 검수 전용 난도 변경/새 작업/설명 버튼 및 중복 헤더 숨김. 기존 부모 임무 시계/보안 추적/작업 중단 및 자동 성공 처리 사용. 작업과 최초 설명은 같은 전체화면 iframe 규격. 도움말에서도 동일한 6단계 시연 재생.
- R6 상하 숫자 조작, 초기 이력 없음, 숫자 중복 금지, 최신순·최신/성공 표시, 기호 범례 상단, 색상별 결과, 440ms 스캔, 1650ms 중앙 자물쇠 상승 연출 유지. 한쪽 다리 연결 유지. 설명 마지막 단계는 입력 상태 350ms 후 같은 검사 함수. 시연은 실제 성공/숙련도/추적 기록에 영향 없음. 감소 모션 설정 존중. 실제 성공 시 부모가 타이머 정지 후 R6 연출 기간을 기다렸다가 권한 부여, 기존 공통 완료 팝업은 ID 11에 한하여 중복 표시하지 않음. 불일치 검사는 오류로 집계하지 않음.
- 640×300 가로 통합 화면에서 임무 헤더로 줄어든 높이에 맞춰 상하 여백, 숫자/버튼 크기를 보정. 승인된 구성과 연출은 유지.
## 24종 체계 및 저장 호환
- ID 10은 영구 폐기 슬롯(null), 기존 ID 11~25는 재사용/재번호화하지 않음. 설비 및 도움말에서 표시 번호만 연속 01~24로 표시. 기존 내부 식별자/과거 기록 보존. 내장 일반 엔진의 구형 추론/탐색 구현 제거하고 남은 23종은 기존 엔진 사용.
- 시험 3 보안 인증 해제: 인증 서버 작업 [10,11]→[11]. 시험은 12개 유지. 기존 시간 산식(120초+작업당 120초)에 따라 시험 3의 제한시간 360→240초. 타이머 및 밸런스 산식 자체 변경 없음. 인증 서버 일반 배정 풀 [11]만 유지. 설비 권한 정책은 보류.
- 기존 저장 데이터 일회성 이전: 추론 숙련도/해금 목록 제거(탐색 숙련도로 승격하지 않음), 기존 시험 완료와 성장/보상/이력 유지. 수락 의뢰·대기 의뢰·특수 의뢰에 남은 ID 10은 ID 11로 대체하며 동일 작업 목록에 이미 ID 11이 있으면 ID 10 제거. 의뢰 ID, 제한시간, 보수, 지도/목표 보존. 난도 표시/발급 지문 갱신. 과거 감사 로그는 역사 기록으로 변경하지 않음.
