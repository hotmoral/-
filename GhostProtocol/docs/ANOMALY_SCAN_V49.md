# 이상 탐지(ID01) — R1~R4 및 통합 v0.49 (2026-11-26)

## 확정 목적·기존 규칙
가상 데이터 스캐너로 기준 코드와 일치하지 않는 모든 코드를 찾는다. 5자리 16진수 기준 코드, 이상 코드는 정확히 한 자리만 바뀐다. 쉬움/보통/어려움의 검사 대상 12/20/36개, 이상 코드 2/3/5개, 열 4/5/6개. 정상 코드 오선택은 기존 오류 정책 유지, 이미 찾은 코드는 중복 선택 금지. 격리·삭제는 사용자가 명시적으로 제외. ID02 일치 검증은 기준과 완전히 일치하는 코드를 찾는 별개 목표로 유지; 기존 대상 12/18/24개, 정답 1/2/3개, 코드 4/6/8자리, 열 4/6/6개. ID02는 미개편이며 화면·연출을 ID01의 정답 조건만 뒤집어 복제하지 않는다.

## 화면·피드백
R1 시범 → 사용자 피드백: 불일치 문자 초록색은 부적절, 기준 코드 아래 빈 대형 스크린의 기능 부재, 정렬 불량 및 설명의 중의성. R2: 좌측 기준 코드·분석 모니터·탐지 현황, 우측 검사 대상. 선택 후 520ms 분석, 기준/선택 코드 문자별 비교·일치 연결선·불일치 위치 표시. 초록색은 탐지 성공 테두리/체크, 주황 사각형 및 짧은 점멸은 불일치 문자, 빨강은 정상 코드 오선택 오류. 선택 전 정답 미노출. 동일 간격·중심축, 패널 경계 및 작은 설명 예시의 가독성 확보. 플레이어가 판단하고 도구는 선택 결과를 검증.
R3: 스캔선과 테두리 생성이 따로 진행되던 문제 수정. requestAnimationFrame의 동일 진행값으로 스캔선과 표시 영역의 클리핑을 갱신하여 위에서 아래로 스캔선이 지나는 만큼 테두리 생성. 종료 후 테두리 유지. 크기 변경 및 감소 모션 대응, 취소 시 예약 동작 폐기. 설명 예시 제목 우측 다시 보기, 하단 동일 폭 이전/중앙 단계 번호/동일 폭 다음. 인증도 v0.48에서 동일 배치.
R4: 사용자가 완료 표시 0.6초는 짧다는 의견에 동의, 1.5초로 확대 후 통합 지시.

## 최종 CIPHER 설명 5단계 (v0.49 소스 대조)
1. 서버에 비정상적인 코드가 섞여 있어. 기준 코드와 일치하지 않는 코드를 모두 찾아내야 해.
2. 데이터 스캐너를 연결해 뒀어. 왼쪽에는 기준 코드가, 오른쪽에는 검사 대상 코드가 표시돼.
3. 두 번째 코드의 세 번째 문자가 기준 코드와 일치하지 않아. 이 코드를 선택하면 스캐너가 불일치한 위치를 표시해 줄 거야.
4. 모든 문자가 기준 코드와 일치하면 정상 코드야. 정상 코드를 선택하면 작업 오류로 기록되니 주의해.
5. 왼쪽 화면에서 탐지 현황을 확인해. 이상 코드를 모두 찾아내면 탐지 작업은 끝이야.

예시 A71F2, 02번 A79F2(3번째 불일치), 08번 A71E2(4번째 불일치). 3~5단계에서 대사 4초 선행, 조작 강조 650ms, 실제 분석 및 결과. 4단계 정상 코드 오선택/오류, 5단계 남은 이상 코드 선택 및 완료 시연. 단계 자동 전환 없음, 이전/재생/취소/시작 시 예약 무효화, 실제 기록과 분리.
