# v0.27 첫 시험 안내 · 보안 추적 · 특수 의뢰 사건
## 첫 시험
미등록 플레이어의 시험 01에 현재 필요한 조작 1개만 강조: 임무 시작→접속 시작→최초 설명 확인→다음 접근 가능한 설비→열람 작업→문제 시작→접속 종료→결과의 다음 시험. 1.65초 주기의 은은한 청록색 테두리/발광, 움직임 감소 설정에서는 정적 테두리. 강제 조작이나 정답 공개 없음. 다른 시험/실전은 기존 UI 유지.
## 보안 추적
기존 규칙 변경 없음. 시험은 추적 없음. 실제 보안 추적이 처음 활성화되는 임무의 최초 설명에 '보안 추적 · 원인과 대응' 추가. 기존 추적 단계 설명과 도움말 연동. 이전에 추적 안내를 본 저장에도 도움말에서 새 설명 확인 가능.
- 0~29 정상, 30 주의, 60 경보(조건 충족 시 일시 단절), 85 긴급, 100 즉시 강제 접속 종료/실패(남은 시간 무관). 정식 의뢰 실패 시 기존 신뢰도 -5(최소 0).
- 시간에 비례해 상승(의뢰 유형 및 등급별 속도). 조건부 시작이면 첫 실제 작업부터 시작. 설명·통신 중에는 정지.
- 주의/위험 설비 첫 실제 작업 +5/+12%p. 동일 설비의 최초 페널티 반복 없음. 퍼즐 해결 시 그 퍼즐 오답 수×0.5%p, 최대 8%p 반영.
- '완화 효과'가 표시된 감시 설비 제어 시 추적률 -25%p, 이후 추적 속도 55% 감소(중복 속도 감소 없음), 제한시간 +45초. 효과 없는 감시 설비에는 적용되지 않음. 단절은 15초 후 복원, 권한 유지.
- 추적 한계 실패 시 결과창에 TRACE 100%·발각·강제 접속 종료 명시, 터미널에도 한계 도달 기록. 기존 보상/실패 산식 유지.
## 특수 의뢰 사건 (신규 발행에만 적용)
|명성|사건명|기반 유형|
|---:|---|---|
|90|지워진 기록|사건 조사|
|200|마지막 사본|자료 복구|
|380|유령 신호|침입자 추적|
|650|침묵의 방어선|시스템 보호|
|1050|검은 관제실|시스템 무력화|
각 사건은 CIPHER 개별 브리핑/성공 대사, 기존 목표 외 별도 설비의 열람 목표 1개를 추가, 게이트웨이 열람 이후 LUNA 분석 보고 1회(통신 중 시간 정지). 실제 추가 목표가 해결 가능한지 검증 후 반영. 미발견 설비 정체는 공개하지 않음. 추가 검증 목표는 처음부터 목록에 있으며 중간 보고가 갑자기 목표를 바꾸지는 않음. 일반 의뢰 3개와 기존에 발행된 특수 의뢰 스냅샷 보존. 기존 보수/등급/명성/난도/기회 소진 규칙 유지. 동일 특수 의뢰 재실행은 처음부터 시작하며 보고도 다시 재생. 새 사건 제목과 대사는 이번 구현 초안.
