# 게임 용어 및 시각 언어 적용 기준 (2026-11-25, v0.36 이후 2단계)
## 범위 및 상태
사용자 승인 UX 개선 방향(UX_REDESIGN_PLAN_V36.md)을 기반으로 v0.36 외부 HTML 및 Base64 내장 퍼즐의 defs 25개, shortTask, conciseRules, puzzleLesson, stateGuides, statuses, renderDetail, 의뢰/성장 표기, 내부 퍼즐의 조작·상태 문구를 직접 대조했다. 이 문서는 구현용 기준안이며 개별 문구와 기호 외형의 최종 실기기 승인은 남아 있다. 이번 작업은 설계 정비만 수행하며 실행본 v0.36, 내부 ID, 데이터, 저장 형식, 퍼즐 생성 및 판정, 권한/추적/성장 수치 변경 없음. 10/11 시범 적용 후 사용자 검수, 승인 전 나머지 23종 일괄 적용 금지.
## 원칙
- 목표/조작은 명확한 한국어로, 반복 상태는 기호+색, 개수는 기호+숫자. 영문은 분위기 및 기술 터미널의 보조 요소. 전문성보다 직관성, 기술 용어를 새로 설명해야 하는 비용을 줄임.
- 하나의 의미에는 동일한 명칭. 목적·행동·상태·수량을 혼동하지 않는다. 고정 폭의 한글 어절 중간 분리 금지, 짧은 명사형 제목·동사형 버튼·완결된 목표 문장으로 구분.
- 기존 캐릭터 설정/말투 유지: CIPHER 여유 있는 반말, ECHO 간결한 작전 지시형 반말, ZERO 신중한 선언형 반말, LUNA 부드러운 존댓말/확인된 정보와 추측 구분. UI 문구는 인물 말투가 아닌 중립 표기. 자동 어미 치환 금지.
- 실제 해킹 절차가 아닌 가상 보안 작업이며, 논리 규칙과 조건·수치·실제 조작을 그대로 전달한다. 정답, 추론 규칙, 일치 위치를 실제 문제에서 노출하지 않는다.

## 10/11 기호 상세 기준 (시범안)
- 초록 체크: 숫자와 위치 모두 같음. 짧은 도움말 '위치까지 맞음'.
- 주황 좌우 화살표: 숫자는 같고 위치는 다름. 짧은 도움말 '숫자만 맞음'.
- 빨강 X: 인증 코드에 없는 숫자. 짧은 도움말 '없는 숫자'.
- 실제 코드의 feedback(a,b)는 exact, common-exact 두 값 반환. X=코드 길이−exact−(common−exact). 기존 중복 금지 코드에서 정보량 및 난도 변경 없음. 세 값은 0도 표시, 순서 고정. 예 123 대 345: 0/1/2; 123 대 132: 1/2/0; 123 대 124: 2/0/1; 123 대 123: 3/0/0. 숫자별 표시나 연결선은 설명 전용 공개 예시에서만. 실제 #10 후보 버튼에는 자동 검사 결과를 붙이지 않음(정답 유도 금지). #11에서 검사 버튼을 실제로 누른 후에만 검사 결과 개수 표시. X 개수는 오답/추적 페널티가 아님.
- 용어: 숨은 코드→인증 코드, 검사 코드→비교 코드(#10)/입력 코드(#11), 후보 코드→인증 후보, 검사 결과 유지. #10 선택, #11 검사 버튼 구분. '검사'와 '인증 성공' 구분.
- 색+형태 동시 구별, 색상 없이도 의미 구분. 실제 플레이에서 기호 의미 재확인 가능. 개별 숫자와 기호의 대응은 설명 모드에서만. 기존 퍼즐 규칙 유지.
- 시연: 공개 예시의 세 가지 비교 관계를 단계별로 먼저 학습→실제 UI와 같은 문제 예시→작업 조작/결과→완료. 이전/다음/현재 다시 보기/건너뛰기/작업 시작. 단계 자동 재생 후 정지, 설명 중 시간·추적 정지, 도움말 재진입 동일 시연. 실기기 승인 전 다른 퍼즐에 확산 금지.
