# v0.38 실기기 피드백 반영
v0.37 삼성 브라우저 가로 화면에서 설명 문구·코드 겹침, 후보/단계 이동 버튼 잘림 및 세로 스크롤, 합의한 기호 외형과 폰트 문자 불일치 확인. 가로 우선 수정.
- 시연 영역을 설명/공용 퍼즐 렌더러/단계 이동 3개 독립 행으로 배치. 중복 내부 제목 제거, 팝업 가용 높이 확보. 좁은 가로 화면에서 코드와 기호 범례 같은 줄, 표 행/간격 조정, 중복 단서 제목 생략. 이동 버튼 하단 고정. 세로 화면은 세로 배열 유지.
- 체크, 양방향 두 화살표, X를 고정 SVG 선형 아이콘으로 제작. 범례/수량/완료 상태/실제 작업과 시연 모두 공용 기호 사용. 비교 코드 예시에서 숫자 열 위치 일치, 대응 숫자 강조. 기존 정답/판정/정보 공개 규칙 유지.
- 검수: 외부 팝업을 상태 주입하여 768×358, 640×300, 844×390, 360×768의 10/11 시연 6단계씩 48개 상태에서 설명/내용/이동 버튼 경계 및 기호 렌더링 검사 통과(버튼 프로그램 클릭). 내장 퍼즐 768×315, 640×257, 360×570에서 10/11×3난도 18개 자동 풀이, 6개 시연 단계 이동/완료/이전 복원 검사 통과. JS 오류 없음. 실제 삼성 브라우저 재검수 필요. 다른 23종 및 권한/밸런스 변경 없음.
- 시범 승인 전 다른 퍼즐 확산 금지. 사용자 화면 캡처는 공개 저장소에 올리지 않음.
