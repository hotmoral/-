## 규칙 및 UI
ID01 기준 코드와 일치하지 않는 모든 코드 선택. 기존 5자리, 대상 12/20/36, 정답 2/3/5, 열 4/5/6. ID02 기준 코드와 완전히 일치하는 모든 코드 선택. 기존 4/6/8자리, 대상 12/18/24, 정답 1/2/3, 열 4/6/6. 정상 코드와 변형 코드 차이 한 자리 유지. 둘 다 오선택 오류 기록 및 중복 선택 금지. 도구의 선택 후 비교, 탐지/검증 카운터, 정상/오류 결과 구별. ID02 완료 문구 '검증 완료'. 격리/삭제 없음.

## ID02 설명
1. 서버에 기록된 코드 중에서 기준 코드와 완전히 일치하는 코드를 모두 찾아야 해.
2. 데이터 스캐너를 연결해 뒀어. 왼쪽의 기준 코드와 오른쪽의 검사 대상 코드를 비교하면 돼.
3. 첫 번째 코드는 마지막 문자가 기준 코드와 일치하지 않아. 이 코드를 선택하면 작업 오류로 기록돼.
4. 두 번째 코드는 모든 문자가 기준 코드와 일치해. 선택하면 스캐너가 일치 여부를 확인해 줄 거야.
5. 왼쪽 화면에서 검증 현황을 확인해. 기준 코드와 완전히 일치하는 코드를 모두 찾았으니 이제 최종 검증을 진행할 거야.
예시 A71F, 01번 A71E 오답, 02번 A71F 정답. 마지막 단계에서 최종 검증 시연. 이전/다시 보기/다음 규칙 공통. ID01 마지막 대사도 선택 조건을 다시 명시. 두 퍼즐 설명/실전 격리. 인증 9단계와 6초 연출 유지.
