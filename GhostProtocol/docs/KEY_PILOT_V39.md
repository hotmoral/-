# v0.39 인증 코드 시범 디자인 보정
사용자가 첨부한 기존 채팅 시연 디자인을 기준으로 10/11부터 수정. 이후 나머지 23종에도 간결하고 직관적인 시각적 설명/표현을 적용하되 시범 실기기 승인 전 변경 금지.
- 공개 예시 코드 123/134의 숫자 블록을 정렬. 정확 일치는 초록 직선, 숫자만 일치는 주황 곡선 점선, 없는 숫자는 빨간 강조/연결 없음. 대응 블록과 설명 옆 기호 카드를 함께 표시. 연결/강조 애니메이션, 감소 모션 존중.
- 초록 체크, 위쪽 왼향/아래쪽 오른향 화살표, 빨간 X의 기존 공용 SVG 유지. 숫자와 기호를 색상별 배경/테두리 카드로 묶음. 실제 작업과 시연에 공통 결과 카드 적용.
- 시연 7단계: 세 기호 학습 → 공개 코드 123에 대해 345/132/124/123을 직접 선택해 결과 비교 → 실제 UI 작업 목표 → 제외/검사 → 인증 완료. 이전/다시 보기/다음 및 기존 작업 시작·건너뛰기 유지. 시연 공개 코드와 실제 문제 상태 분리. 실제 정답 판정·난도·권한 변경 없음.
- 가로 화면은 숫자 비교와 설명 카드를 옆에 배치, 세로는 아래에 배치. 작은 가로 최종 단계에서 성공 상태를 상단에 배치해 겹침 제거.
- 검수: Chromium 내장 iframe 크기 768×235,640×185,844×265,360×570에서 2종×7단계×4화면 56개 상태 검사, 시연 선택 예시 결과 3/0/0 확인, 설명/내용/이동 버튼 경계 겹침 0건. 실제 내장 768×315,640×257,360×570 2종×3난도×3화면 18개 자동 풀이 성공, JS 예외 없음. 외부 팝업 전체 흐름과 삼성 실기기 재검수, 다른 23종 전체 회귀 검수는 미실시. 다운로드 파일과 GitHub blob 동일.
- 이후 기준: 시각 요소가 설명을 대체할 수 있는 부분은 시각화, 한 단계 한 개념, 글은 짧고 자연스럽게, 시연 전용 정보와 실전 정답 비노출 구분. 실제 조작·규칙 유지. 가로 우선/세로 보조.
