# v0.28 추적 피드백 및 1차 밸런스 검수 (2026-11-25)
## 추적 연출
기존 상단 TRACE 수치에서 상승/하락 숫자 보간(약 420ms), 발광 및 1.35초 비차단 표시. 주의/위험 설비 첫 작업, 오답, 감시 제어는 실제 변화량과 원인을 표시. 시간 경과는 정수 변화 시 짧은 발광, 단계 전환은 주의/경보/발각 임박 표시 및 터미널 기록. 30/60/85% 자동 경고 팝업과 실제 단절 발생 팝업 제거. 최초 보안/단절 설명, 실제 단절·복구, 임무 제한시간 경고, 100% 강제 종료 결과, 스토리 통신은 유지. 숫자는 표시만 보간하며 내부 trace 값/실패 판단은 즉시 반영. 감소 모션 설정 존중. 지도 HUD 아래 및 퍼즐 헤더 옆 표시(제목/버튼 겹침 방지), 레이아웃 이동 없음.
## 밸런스 변경
신규 발행 A 추적 배율 1.35→1.30, S 1.50→1.40. 나머지 등급·제한시간·난도 비율·보상/승급 조건 유지. 기존 발행 및 수락 스냅샷의 보안 속도는 바꾸지 않는다. 실제 플레이 로그가 없으므로 임시 보정.
