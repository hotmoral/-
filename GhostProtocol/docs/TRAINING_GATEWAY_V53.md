# 입문 시험 게이트웨이 사전 접속 승인 — v0.53

## 승인된 범위
1번 시험: 게이트웨이 일치 검증(ID02) 그대로. 3·5·6·7·8번 시험: 기존 생성 코드가 핵심 설비 앞에 퍼즐 없는 게이트웨이를 배치한다. 해당 5곳에만 사전 승인 설정 및 연출 추가. 2·4·9·10·11·12번은 게이트웨이 없음, 새로 추가하지 않음. 일반 의뢰는 게이트웨이 ID02 또는 ID04(패턴 탐색)를 배정하며 특수 의뢰도 기존 생성에 기반하므로 그대로 유지. 연계 인증 등 다른 기존 권한 처리 유지. 일반 설비의 즉시 열람 권한 개연성은 아직 별도 논의 대상.

## 구현
- 기존 시험 브리핑의 핵심 대사를 유지하며 첫 해당 시험에서 CIPHER의 '게이트웨이의 접속 권한은 미리 등록해 뒀어.'를 덧붙임. 최초 사전 승인 완료 후 gatewayPreapprovalSeen 저장. 재실행 시 반복 안내 생략.
- 설비 상세: 사전 등록된 접속 권한, 접속 승인 확인 버튼. 누르면 권한 확인 중 표시 및 터미널 로그. 지도 연결선에 0.95초 발광 신호/선 그리기, 0.35초 도착 링, 1.3초 시점 기존 apply/read 실행, 권한 점등 및 후속 설비 발견. 기존 지도 이동 보간 유지, 필요한 경우만 지도 맞춤. 감소 모션에서 선과 링 즉시 표시. 추가 완료 팝업 없음(기존 발견 설비 안내는 유지).
- 실제 작업으로 임무 시간은 계속 흐름. 중복 조작 방지, 재시작/임무 종료 시 예약 동작 취소, 시간 초과 및 네트워크 변경 방어. 기존 저장 기록 호환. 별도 퍼즐 성공 및 숙련 보상 없음.
- 생성/판정/핵심 퍼즐 및 기존 성공 효과 변경 없음.
