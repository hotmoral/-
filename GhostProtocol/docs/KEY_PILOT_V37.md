## 시범 구현
- 목표 인증 코드의 자릿수 → 단서 또는 검사 이력 → 후보 선택/입력으로 시선 흐름을 구성. 이전의 거대 분할 버튼 폐기. 세 기호(초록 체크=숫자·위치 모두 같음, 주황 ↔=숫자만 같음, 빨강 ×=없는 숫자)를 개수와 함께 표시. 짧은 기호 범례 유지. 0도 표시. 후보에는 실제 검사 결과를 붙이지 않음. #11 검사 누른 뒤에만 결과 추가. 정답 확인 전 숨은 코드의 숫자/위치 비노출. 코드 중복 금지 및 기존 판정 유지. 인증 완료 시 선택된 코드와 성공 표시, 검사 결과 수신 발광. X 수량은 실제 오류 횟수 아님.
- 내장 퍼즐 keyPanel 공용 렌더러를 사용해 시연의 4~6단계와 실제 작업 UI를 동일하게 구성. 1~3단계는 공개 코드 123과 134의 비교로 기호 학습, 이후 4 목표·단서/입력, 5 제외 또는 검사, 6 인증 완료. 단계 이동 및 재생 후 정지, 이전/다시 보기/다음, 마지막 처음부터, 외부 작업 시작·시연 건너뛰기 제공. 도움말에서도 동일 시연을 호출. 예시는 실제 문제 생성과 별도 상태(config.demo), 실제 ready/success/stats 이벤트 전송 없음. 시연은 고정 예시이며 일반 퍼즐 기록/정답 판정에 반영되지 않음. 설명 모달의 기존 시간 정지 흐름 사용. 애니메이션은 강조 및 마지막 결과 전환 중심의 첫 시범이며 사용자의 실제 체감 검증 전 확정하지 않음.
## NPC 문구 검토
사용자 지적: 인물 추적 브리핑 "대상의 통신 흔적을 확보해. 추적에 필요한 기록을 우선 확인해."는 같은 지시 반복. "대상의 행적을 확인할 수 있도록 통신 기록을 확보해."로 수정. 12개 일반 브리핑 전부 재작성, 시험 브리핑/결과 12종, 프롤로그 선택 대화, 등록·인계·첫 분석, 경고·실패·성공, 설비 및 상태 설명, 특수 의뢰 5종의 브리핑·LUNA 보고·결과 소스 검토. 어색한 일부 문구 및 동일 지시 반복 교정. ECHO는 목표와 행위가 자연스럽게 연결된 지시, CIPHER는 여유 있는 반말, LUNA는 확인된 정보와 추가 자료의 필요성을 구분, ZERO의 기존 승인 문구 유지. UI는 중립 문구. 게임 규칙을 새로 만들거나 정답/미발견 설비를 대사로 공개하지 않음. 모든 팝업을 실제 플레이에서 재생 검수한 것은 아니며 남은 퍼즐 개별 재설계에서 문맥·실기기 재검수 계속.
