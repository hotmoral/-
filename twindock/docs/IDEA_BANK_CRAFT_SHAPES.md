# Twin Dock — Idea Bank: Craft Shape Variants

Status: **BANKED ONLY**. This file is not a roadmap and does not promote any shape to candidate/validated status.

Purpose: preserve the idea that player-craft silhouette itself can become a gameplay variable, not merely cosmetic art. Any later promotion still follows `BANKED -> CANDIDATE -> VALIDATED -> ROADMAP` through the main content-expansion process.

## Shape families to keep banked

- L / ㄴ-shaped craft: offset mass/silhouette with inner-corner clearance problems.
- ㄹ-shaped craft: multiple protruding arms creating rotational sweep and approach-path constraints.
- ㅂ-shaped / double-bay craft: enclosed or semi-enclosed internal spaces with unusual port placement possibilities.
- Circular craft: weak inherent forward direction; active port and RCS orientation become more important to read.
- Elliptical craft: elongated rotational clearance without a conventional nose/tail silhouette.
- Triangular craft: strong directional readability with alternative corner/edge port placements.
- T-shaped craft: wide crossbar creates large rotational clearance and nonstandard port positions.
- Cross-shaped craft: several protrusions can make rotation near structures the dominant problem.
- Ring / annular craft: docking anchor can sit on the rim or inner edge; rotation moves the port through a large arc.
- Long bar / cargo-barge craft: mid-body port with large fore/aft sweep and clearance risk.
- Fork / U-shaped craft: target or station geometry may need to enter between two arms.
- Concave craft: docking point can sit inside a notch or recess rather than on the outermost nose.
- Strongly asymmetric craft: visual center, physical body extent, and docking anchor can all differ substantially.
- Irregular / non-geometric craft: intentionally nonstandard silhouette if it creates a readable, distinct spatial docking problem.

## Design-use note

The shape is only valuable if it changes the physical/spatial problem. Future evaluation should ask whether the silhouette creates a distinct combination of:

- docking-anchor position
- docking-anchor orientation
- rotational swept area
- translational clearance
- approach-direction constraints
- collision risk away from the docking point
- readable failure/recovery behavior

A strange silhouette by itself is not sufficient reason to promote it.

## World/fiction note

Unusual shapes do not need to resemble atmospheric aircraft. In an orbital/service-craft setting, function-driven shapes can plausibly be highly asymmetric, circular, angular, concave, modular, or otherwise unconventional. Visual language should still make the active docking port and craft orientation understandable during play.
