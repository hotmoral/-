# 3. Distributed vs clustered durable pressure

Repeated durable arrivals were tested across a 60s stress horizon.

## Distributed durable pressure

Two durable bodies arrive in separated geometry across each pressure cycle.

### Mage

Wall trajectory under all-success Lv31 play:

```text
30s -> 2000
40s -> 1360
45s -> 1040
50s ->  720
55s ->  400
60s ->   80
```

At 60s the Mage path had 12 durable wall contacts.

One missed final buried around `56.375s`; two consecutive missed finals buried around `51.775s`.

Interpretation:
- distributed durable pressure is a genuine Mage mastery lever;
- it does not require reducing Arcane Collapse damage/radius;
- sustained separation prevents one collapse package from solving every durable body;
- however using this full 60s density as exact campaign content would likely be too harsh and is not approved.

## Clustered durable pressure

Three durable bodies arrive close enough for Mage's density package to exploit clustering.

Mage all-success result:

```text
60s wall = 2000
```

The same durable concept therefore gives Mage both a weakness and an answer:

```text
distributed durable -> accumulating unresolved pressure
clustered durable   -> Arcane Collapse regains large payoff
```

This is exactly the desired class-asymmetric authoring behavior.

Classification:

```text
TANK_SURVIVAL_IS_CONTROL_DRIVEN = TRUE
TANK_DAMAGE_NERF_JUSTIFIED = NO
DURABLE_PROXY_HARD_COUNTERS_TANK = NO
```

This is important: Tank's large miss tolerance in prior probes is not evidence that its final is simply overpowered numerically. Its class identity is successfully converting damage pressure into time.

Future authoring must pressure the **time budget** rather than delete Tank's control tools.

# 5. Role-pulse experiments

Several post-reset role-pulse patterns were checked directionally.

## Too aggressive pattern — reject as default

Repeated every-cycle:

```text
two distributed durable bodies
+ deep SIEGER pulse
+ deep CHARGER pulse
```

Directional all-success result:
- Knight survives comfortably;
- Rogue survives but takes material pressure;
- Tank survives through control/shield;
- Archer takes substantial SIEGER pressure;
- Mage can be buried even with every final successful.

Verdict:

`TOO_HARSH_AS_DEFAULT_STAGE48_49_RECIPE`

Do not use this as the universal late-game pattern.

## Moderate role pulse — promising for Stage48-like pressure

A lighter pattern using one alternating durable body plus intermittent deep SIEGER/CHARGER produced an all-success survivable band for all classes.

Representative all-success wall outcomes across tested moderate variants:

```text
Knight ~1890..2000
Rogue  2000
Tank   2000
Archer ~1775..1890
Mage   ~710..1040
```

Interpretation:
- Mage is meaningfully pressured without automatic failure;
- Archer pays for off-corridor role threats but remains viable;
- Tank control remains strong;
- Knight/Rogue are not killed first by generic pressure inflation.

This is a plausible Stage48 authoring direction.

## Stronger durable + SUPPORTER/SIEGER pulse — promising Stage49 diagnostic

A stronger repeated pattern with distributed durable front pressure plus timed SUPPORTER/SIEGER second pulse produced:

### All-success

```text
Knight 1850
Rogue  2000
Tank   2000
Archer 1255
Mage    560
```

### One missed P×P

```text
Knight 1775
Rogue  1925
Tank   1226
Archer 1255
Mage    400
```

### Two consecutive missed P×P

```text
Knight 1550
Rogue   950
Tank   1092
Archer 1255
Mage    400
```

This is not balanced/frozen content, but it demonstrates a useful late-mastery property:
- Tank all-success control can hold the line;
- missed final windows materially reduce Tank's safety margin;
- Mage is already under heavy all-success pressure, so this exact intensity needs spacing/cadence reduction before campaign admission;
- Knight/Rogue remain viable rather than being the first automatic casualties;
- Archer's vulnerability comes mainly from off-corridor SIEGER exposure, which is a role/geometry issue rather than a raw damage issue.

# 6. Stage48 -> Stage49 escalation direction

The best current direction is **not one universal pressure recipe**.

Recommended authoring progression:

```text
Stage46..47
  power revelation
  Lv31 finals feel spectacular

Stage48
  one durable threat at a time / alternating geometry
  intermittent readable SIEGER or CHARGER second pulse
  all-success remains clearly recoverable

Stage49
  distributed durable pair / protected role threat
  second pulse arrives after the first flashy reset
  missed P×P windows convert backlog into real wall danger

Stage50
  synthesize durable + line + cluster + role timing
  without introducing an unpreviewed mandatory mechanic
```

This preserves the user's intended late-run progression:

```text
Lv31 acquired -> enormous power
then
encounters learn how to absorb that power
then
mastery is maintaining timing/combo/P×P under layered pressure
```

# 7. Class-specific interpretation

## Knight
Durable pressure is not a hard counter. Two-wave chunking leaves meaningful cleanup work while preserving frontline break identity.

## Rogue
16-dagger execution remains valuable. Repeated distributed durable targets consume the storm target-by-target rather than letting one cast erase every lane.

No dagger-count nerf is justified.

## Tank
The key resource is **time**, not damage. Knockback/barrier must remain valid. Authoring should create second pulses that consume the time Tank buys, not invalidate push with extreme resistance.

## Archer
Armor ignore remains a premier durable answer, but off-corridor role threats still matter. This supports the approved wider-but-straight final corridor.

## Mage
Distributed durable pressure is the strongest new lever. Clustering restores Mage's advantage, so the weakness is positional/authoring-dependent rather than a permanent class tax.
