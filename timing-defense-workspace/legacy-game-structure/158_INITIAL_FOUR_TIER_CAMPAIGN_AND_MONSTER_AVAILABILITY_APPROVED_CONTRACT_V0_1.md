## 1. User approval

The user approved the recommended Candidate A package on 2026-10-24.

Adopted initial campaign constraint:

```text
Initial campaign Tier count = 4

T1 = GRUNT / RUNNER / BRUTE
T2 = T1 + SHIELD / FLYER
T3 = T2 + CHARGER / SPLITTER
T4 = T3 + SUPPORTER / SIEGER
T5+ = future monster expansion space
```

This is now canonical campaign-authoring authority.

## 2. Exact meaning of adoption

The following are now fixed structural constraints unless reopened by explicit user decision or concrete contradictory evidence:

- launch/initial campaign uses four Tiers;
- each Tier remains 50 Stages;
- T1 exact ordinary roster constraint is `GRUNT / RUNNER / BRUTE`;
- T2 first makes `SHIELD / FLYER` available;
- T3 first makes `CHARGER / SPLITTER` available;
- T4 first makes `SUPPORTER / SIEGER` available;
- earlier unlocked monsters remain available in later Tiers;
- current nine ordinary monsters are not a lifetime roster cap;
- T5+ must remain extensible for future monster/content expansion.

## 3. Fallback boundary

The prior split-five-Tier model is not active authority.
It remains a predefined fallback only if lower-layer authoring/simulation/playtest produces concrete evidence that combined T4 cannot preserve:

- SUPPORTER/SIEGER learning separation;
- readable minimum role expression;
- class-opportunity coverage;
- objective-pressure readability;
- acceptable cognitive load.

Fallback trigger is evidence-based. Do not split T4 preemptively.

## 4. Mandatory T4 guardrail

The adopted T4 pair carries this structural guardrail:

```text
SUPPORTER isolated teach/mix first
-> SIEGER isolated teach/mix later
-> combined support/siege only after both are independently readable
-> no first teach of either core mechanic in Stage41-50
```

`T4_SUPPORTER_SIEGER_LEARNING_DENSITY_WATCH` remains active.

## 5. P6 consequences preserved

This Tier adoption does not undo P6 findings:

- encounter family can materially rotate class advantage;
- no single late-stage class ranking is a universal balance ranking;
- Tank remains control/defense/objective-protection specialist and does not require kill parity;
- shop ATK / EXP feedback remains bidirectional and outcome-conditioned;
- provisional pure-per-root-action EXP still carries class-progression divergence pressure;
- fresh-forward magnitude remains a watch, not exact production authority.

## 6. Not adopted by this contract

This approval does **not** freeze or authorize:

- exact Stage1-50 recipes;
- exact first-teach Stage numbers inside the allowed Tier;
- encounter frequency counts;
- exact formation/cadence timing;
- monster HP/speed/damage/capability coefficients;
- boss cadence or boss mechanics;
- exact EXP formula or milestone distribution;
- shop values;
- class buffs/nerfs;
- P×P/judgment probabilities;
- production gameplay changes.
