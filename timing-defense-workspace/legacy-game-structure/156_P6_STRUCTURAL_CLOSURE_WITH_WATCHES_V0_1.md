## 2. Why closure is justified

Independent bounded slices now agree on the important topology.

### Encounter opportunity
Class order rotates materially by encounter family.
Therefore one late fixture is not universal class-power authority.

### Tank role
Tank is a control / defense / wall-protection specialist.
Low removal is not by itself a defect.
P6 evidence shows control and defensive tools can reduce objective pressure.

### Shop / EXP feedback
Shop ATK can:
- reduce same-stage timing opportunities by killing faster;
- increase total run opportunities when it prevents failure and reaches later Stages.

Therefore global shop->EXP feedback is bidirectional and outcome-conditioned.

### Progression feedback
Fresh-forward independently reconfirmed:

```text
offensive skill/shop power
-> faster or broader removal
-> generally fewer later root timing actions
-> fewer provisional per-root EXP awards
-> later milestone pressure
```

The one reported Archer SPLITTER chronology exception remains a legitimate discrete ordering effect and is not erased.
