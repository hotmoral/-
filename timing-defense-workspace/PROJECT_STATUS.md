# Fortification invariant

Approved formula:

```text
wallMaxHp += delta
wallCurrentHp += delta
```

Existing absolute damage deficit is preserved:

```text
(max+delta) - (current+delta) = max-current
```

Therefore Fortification adds usable reserve but does not erase old attrition.
