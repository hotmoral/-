# ReadingFlow — 신규 비문학·문항 생성 통합 기준 (2026-11-22)

> **2026-11-22 적용 범위 업데이트:** 현행 신규 원고 작성 규칙은 유지하되 **기존 30편·90문항 추가 수정을 중단**한다. 다음 우선 업무는 실제 신규 생성·검수 게이트 연결. [최신 전환 지시](CURRENT_WORK_SCOPE_AND_NEXT_STEPS_2026-11-22.md).

상태: **확인된 사용자 합의와 최신 문항 교정에서 얻은 재발방지 규칙**. 2026-11-13~22까지 접근 가능한 저장소·대화 근거를 대조한 것으로, 과거의 모든 대화 원문을 전수 복원했다고 주장하지 않는다.

**새 지문 제작 세션은 이 파일부터 읽는다.** 기존 `INTEGRATED_RULES_v3.md`, `AGE_GROUP_WRITING_AND_QUESTION_LANGUAGE_RULES_v1.md`, `planning/*`, `AUTOMATED_PRODUCTION_PIPELINE_v1.md` 및 아래 연결자료와 함께 사용한다. **명시적인 최신 사용자 결정이 구버전의 일반적인 권고보다 우선**한다.

## A. 원고 제작에서 확정된 원칙

1. **사실 기반 자체 창작 한국어 비문학만 제작**. 문학은 제작 대상 제외. 교과서·학습지·수능·문제집은 교육적 글/발문 **관습과 사실 확인**용 참고이며 보호되는 문구·창의적 지문/문항을 복제하지 않는다. 외부 원문 수집 라이브러리는 자체 창작 원고/이용 승인과 구별한다.
2. **5연령군 × 각 L1~L6**: 초등 저학년, 초등 고학년, 중·고등학생, 성인, 고령층. 난도는 해당 군 내 상대 단계. 고령층 사고력을 나이만으로 낮춰 설정하지 않는다.
3. 본문 기본 서술체: **`~다/~이다/~한다` 문어체**. 인용·의도적 질문 등은 기능에 맞게 자연스럽게. 발문은 본문 문체와 별개이며 연령별 교재의 실제 표현 방식을 참고한다.
4. **사실·근거의 정확성 > 독해 목표 > 연령·난도 적합성 > 논리적 자연스러움 > 필자 속성 구현 > 참고 분량**. 글자 수를 맞추기 위한 군더더기·인위적 문단 추가·필수 근거 삭제 금지. 분량·난도는 분리.
5. 난도는 **관계 수, 정보 분산, 추론 거리, 조건·예외, 추상성·근거 평가 부담**으로 조절한다. 읽기 동작은 사실 확인/핵심 파악/비교/인과/통합/추론/근거 평가; 고차 사고를 L6의 전유물로 만들지 않는다. 전문어만 늘려 난도를 조절하지 않는다.
6. **대분야→세부 분야→개별 주제→핵심 질문→독해 목표(1~3)→사실/출처→24개 필자 속성 추출→본문→문항·해설·훈련 파생**. 주제 선정·목표·사실은 필자의 스타일과 독립. **18대분야·298세부분야는 가변·확장 가능한 분류 제안**이고 주제 자동 선정의 구현/승인 완료가 아니다.
7. 필자 **24속성 각각의 후보를 원고마다 독립·균등 무작위 추출**, 현행 후보 풀 **172개**. 충돌 때문에 임의 재추첨/가중하지 말고 적용·부분 적용·제한 및 이유를 기록한다. 추가 12개 후보는 미승인 제안. 전개/문단/정보 순서도 기존 24속성의 책임이며 별도 정보 구조 RNG 추가 금지. 추출 로그만 보고 실제 문체 차이가 있다고 선언하지 않는다.
8. **사실·추정·가설·의견과 상관·인과를 구분**한다. 확인하지 않은 숫자·인용·법령·출처를 지어내지 않으며 검증된 증거 위치/시점을 남긴다. 지문 논리가 일관되고 비문·뜻이 성립하지 않는 결합(예: '젖은물')·불필요한 반복이 없는지 검사한다.
9. 같은 소재보다 **핵심 개념·설명 기작·논증 흐름·독해 목표·질문 기능·필자 표현의 중복**을 점검. 연령별로 명확히 심화된 나선형 학습은 허용. 메타데이터만으로 의미 중복이 없다고 주장하거나 자동 삭제하지 않는다.

## B. 연령별 글 형식·발문 (중심 방향, 배타적 장르 제한 아님)

| 연령군 | 주된 비문학 형식 | 발문·난도 특징 |
|---|---|---|
| 초등 저학년 | 현대 생활·학교·어린이 교양·자연 관찰/설명 | 구체적 대상과 쉬운 어휘, 완결된 자연스러운 `~나요?/~인가요?`형. 유치한 내용과 사실 암기만의 반복 금지 |
| 초등 고학년 | 교과 연계 탐구, 현상의 원리, 비교·조건 설명 | 교과서/학습지형 원인·비교·조건·근거 질문. 불필요한 생략형/비문 방지 |
| 중·고등학생 | **수능 국어 독서형 비문학 중심**, 개념·관계·추론·자료 해석 | 시험형의 정확하고 자연스러운 문어체, 지문 내 논리 범위 명확화. 어린이식 `~나요?` 일괄 반복 금지 |
| 성인 | 심화 교양·전문 분석·논증; 필요하면 LEET식 논리 참고 | 자연스러운 분석/평가형 완결 질문. 정답에 필요한 정보는 본문에 제공 |
| 고령층 | 교양·시사·현대 생활·공공정보 등 폭넓게 | 가독성 높은 성인용 문장, 필요한 경우 `~요?`. 유아화·고차 사고 원천 배제 금지 |

문항의 말투는 군 안에서 일관되게. **`글에 따르면`을 기계적으로 붙이지 않고** 의미상 문항 범위를 한정해야 할 때만 사용한다. 교재 표현의 관습을 참고하되 실제 문항을 복제하지 않는다.

## C. 새 객관식 문항의 작성 순서 (대체로 지문당 3~6문항, 현재 시범은 3문항)

1. **독해 목표별로 질문을 먼저 분리**한다. 지문 하나에서 세 문항의 질문 대상과 핵심 근거가 실질적으로 달라야 한다. 세 문항을 동일한 문장/이유만 바꿔 묻지 않는다.
2. 질문의 대상·시간·주체·수량·비교 기준·원인·조건을 명시하고 **완결된 자연스러운 질문**을 쓴다. 조사·시제·주어/서술어·선지와의 문법적/의미적 호응을 검사한다. '질문에 쓰인 어구만으로 답이 뻔한' 지엽적 문항도 피한다.
3. **정답 문구·정답의 원문 근거 구절/위치**를 적는다. 직접 진술, 여러 문장의 결합, 추론인지 구분하고 결론에 필요한 모든 정의·전제를 지문 안에 제공한다.
4. **매력적인 오답 3개**는 원문에 관련된 **부분적 사실+결정적 조건의 오류**, 주체·시점·장소/순서 혼동, 인과 방향 착각, 수치·비교 대상 오독, 서로 다른 문장의 잘못된 결합, 그럴듯하지만 이 질문의 범위에서 지지되지 않는 주장으로 만든다.
5. **각 오답에 정확한 원문 근거와 '왜 틀린지'를 별도로 기록.** 정답과 오답을 모두 지문에 대입하고, 지문상 둘 이상 정답이 가능하면 `HOLD`하고 재설계한다. 현실에서는 가능한 다른 주장도 질문이 지문의 명시적 진술을 물을 때만 '미언급'으로 제외할 수 있다.
6. **엉뚱한 대상·비문·물리적으로 성립하지 않는 문장·노골적 반대·무관한 숫자·관념 밖 단어 결합**으로 쉽게 제거되는 오답 금지. '모든/언제나/반드시/전혀/무조건' 등의 절대 단정형이 오답에만 몰리지 않도록 검토. 정답 유일성·안전성을 위해 일부 구분 쉬운 오답은 허용한다.
7. **정답이 다른 보기보다 유일하게 짧은지뿐 아니라 유일하게 긴지도** 함께 검사한다. 정답 길이를 억지로 늘리거나 오답을 의미 없이 줄여 정답이 유일하게 길어지면 다른 방식의 단서 누출이다. 숫자상 동일 길이보다 한국어의 자연스러움·내용 타당성이 우선.
8. **안전·건강·복약·이동안전**에서 위험 행동을 '매력적 오답'으로 미화하거나 실행할 만한 권고처럼 만들지 않는다. 단일 정답과 안전을 위해 다소 쉽게 제거되는 오답은 허용.
9. **정답에 필요한 내용이 본문 밖에만 있다면 결함**. 그러나 **지문을 읽지 않아도 학습자의 기존 배경지식으로 정답을 예상할 수 있다는 점은 결함·감점·수정 기준에서 제외**(2026-11-22 사용자 확정). '필수 정보가 없음'과 '답을 이미 알고 있음'은 전혀 다르다.
10. 문항마다 질문-정답·세 오답-근거·동일 지문 내 세 문항 기능 분리·연령 문체·정답 길이 양방향·안전·사실/추론을 각각 재검토. 자동 형식 테스트만으로 실제 문법/의미 PASS를 선언하지 않는다.

## D. 과거 수정에서 실제로 반복된 실수와 금지 조치

| 실패 | 새 원고 제작에서 방지할 방법 |
|---|---|
| 터무니없는 오답 때문에 답이 뻔함 → 정답을 고쳐서 해결 | **오답 3개의 지문 근접성과 각각의 반박 근거부터 고친다.** 기존 문항의 정답/라벨은 절대 임의 변경 금지 |
| 오답을 그럴듯하게 고쳤더니 두 개가 정답 | 보기를 하나씩 지문에 대조, 정답 유일성 우선, 보류·재설계. 억지로 정답만 좁히지 않음 |
| 잘못된 표현·비문·상식적으로 말 안 되는 대상/선지 | 조사/호응/시점/수량·인과와 한국어의 실제 쓰임을 사람이 별도 판정 |
| 정답만 매우 짧음 → 오답을 줄였다가 정답만 매우 길어짐 | **최단·최장 양방향 길이와 정보 밀도 확인**. 길이 맞추기를 위한 군더더기 금지 |
| '글에 따르면' 반복, 초등식 질문을 수능형까지 적용 | 연령군별 자연스러운 질문 형태 유지; 문항별 필요한 경우만 한정어 사용 |
| 중복 문항과 비슷한 논증을 다른 제목으로 양산 | 독해목표·근거·원고 간 설명 기작/논증 구조를 각각 비교 |
| 배경지식으로 풀린다는 이유만으로 정답/문항 수정 | **최신 확정 기준에 반함**. 문항 내용 품질과 배경지식을 분리 |
| 위험한 복약·이동 행동을 그럴듯한 오답으로 개선 | 안전 우선, 무리한 변별력 개선 금지 |
| AI 검토·코드 구조검사를 독립 검수/출판 승인으로 보고 | `AI_CANDIDATE`/`STRUCTURAL_PASS`/`HOLD`/`HUMAN_REVIEWED`/`RELEASE_APPROVED` 단계 분리 |

## E. 기존 90문항의 수정 권한과 새 문항 제작 권한 구분

- **기존 R1-A 오답 전용 수정:** 원래 질문·정답 문구·정답 위치·원고 모두 고정. 오답만 수정, 위험한 문항은 보류. 별도 발문 교정 승인을 받은 R5/R6 코호트도 해당 범위에서만 질문 수정 허용. 원복 시 정상 작업은 유지한다.
- **새 원고/문항 초안:** 질문·정답·오답을 새로 설계하고 내부 검수 전까지 수정 가능. 단, 정답을 바꿔 오답 변별력 문제를 감추거나 변경 후 지문·해설·학습 데이터의 종속 검사를 생략하지 않는다.
- 사람이 하는 **지문 미제시 1단계 검수는 보기에 나타난 표면적 힌트/비문** 확인을 위한 용도로도 쓸 수 있다. 이때 '배경지식으로 풀 수 있음'은 불합격 사유가 아니다. **지문 제시 2단계**에서 각 보기의 '지지/반박/지문으로 판단 불가'를 검증하고, 독립 사람 검수·학습자 응답 통계는 별도 단계로 관리.
- 사용자가 줄인 **편집 QA 작업 단위는 1회 최대 5편·15문항**. 신규 대량 생성 물량이나 일반 지문의 문항 수까지 기계적으로 고정했다는 뜻이 아님.
- **최초 30편·90문항 R6.9-B는 AI 검토 후보**로서 기존 문항의 제작 문제를 찾아 교정한 자료. 이것이 새 원고 자동 생성 파이프라인, 실제 변별도 검증 또는 배포 승인을 완료했다는 뜻은 아님.
