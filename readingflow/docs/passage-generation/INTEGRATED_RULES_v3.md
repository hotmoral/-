# 비문학 원고 자동 생성·검수 통합 규칙 v3

> **신규 제작의 최우선 규칙 (2026-11-22):** [NEW_PASSAGE_AUTHORING_AND_MCQ_CANONICAL_2026-11-22.md](NEW_PASSAGE_AUTHORING_AND_MCQ_CANONICAL_2026-11-22.md) + [실행 체크리스트](operations/quality/new_passage_question_creation_checklist_v1.json). 배경지식만으로 지문 없이 정답을 추측할 수 있다는 점은 결함·수정 사유가 아니며, 본문이 필수 근거를 제공해야 하는 의무는 그대로다. 기존 고정 답안 수정은 신규 문항 설계와 구분한다.

상태: **개발 적용용 설계안**. A~E 원고 생성 실험을 통합한 결과이며, 실제 학습자 대상 난도 타당화는 미실시.

> **2026-11-21 누락된 기존 합의 복원:** 연령군별 지문 형식(초등 저/고, 중·고 수능 독서형, 성인 심화 교양·분석/LEET 참고, 고령층 교양·생활·공공정보), 시중 교과서·문제집·학습지 발문 참고, 질문 종결 어미와 비문·호응 점검, 사실·추정·가설·의견 구분의 상세 제작 규칙은 [AGE_GROUP_WRITING_AND_QUESTION_LANGUAGE_RULES_v1.md](AGE_GROUP_WRITING_AND_QUESTION_LANGUAGE_RULES_v1.md)를 **함께 적용한다**. 과거 누락/부분 반영 감사는 [WRITING_DECISION_HISTORY_RECONCILIATION_2026-11-21.md](reviews/WRITING_DECISION_HISTORY_RECONCILIATION_2026-11-21.md) 참조. 기존 R4 90문항은 질문·정답 동결이며 이 복원으로 직접 수정하지 않는다. 모든 과거 대화 내용까지 완전 복원했다고 간주하지 않는다.

**본문·발문 문체의 구별 (2026-11-14·18 합의):** 본문은 연령군 공통 `~다 / ~이다 / ~한다` 평서형 문어체를 기본으로 한다. 질문은 이와 별개로 연령별 실제 교과서·문제집 관습을 참고하되 군 내 일관성을 유지하며 `글에 따르면`을 기계적으로 반복하지 않는다. 기존 작성 원고의 `~습니다` 본문이 확정 기준과 맞는지 별도 감사한다. 이 사항을 원문이나 정답에 자동 수정하지 않는다. 세부 `AGE_GROUP_WRITING_AND_QUESTION_LANGUAGE_RULES_v1.md`.

## 적용 범위·우선순위
- 초등 저학년, 초등 고학년, 중·고등학생, 성인, 고령층 × L1~L6.
- 사실 기반 **독창적 비문학**. 타인의 문장·고유 표현 무단 복제 금지. 허위 출처·수치 금지.
- 우선순위: **사실 정확성 → 독해 목표 → 연령·난도 적합성 → 논리적 자연스러움 → 필자 스타일 → 권장 분량**.
- 글자 수를 맞추려고 설명을 억지로 추가하거나 필수 근거를 삭제하지 않는다.

## 생성 입력 계약
필수: `age_group`, `level`(L1~L6), `topic`(또는 자동 선정).
선택: `length_target`, `length_tolerance`, `genre`, `learner_performance`, `reading_objectives`(1~3), `source_facts`, `avoid_recent_topics`, `seed`.
- 분량은 난도와 **독립 파라미터**. 초기 분량표는 권장값이며 강제 조건이 아님.
- 실제 수행 이력이 있다면 연령에 따른 초기 가정보다 우선하여 난도·분량·보조 설명 조절.
- `seed`는 재현 실험용. 서비스에서는 매 원고 필자 속성 24개 독립 추출.

## 난도 정의
- L1→L6은 단순한 글자 수 증가가 아니라 **관계 수·근거 분산·추론 거리·조건/예외·추상성·근거 평가 부담**의 전반적 상승.
- 사실 확인·비교·인과·추론·통합·평가 활동은 모든 단계에서 사용 가능. 고차 사고 자체가 특정 L만의 독점 영역은 아님.
- 동일 L은 연령군 간 동일 절대 난도를 의미하지 않음.
- 어린 학습자에게도 충분한 구체적 정보와 근거가 있다면 높은 수준의 추론을 요구할 수 있음. 초등 고학년 L6에 정수장 운영 같은 전문 실무 지식을 요구하지 않음.
- 고령층의 사고력 상한을 연령만으로 낮추지 않음.
- 전문어·문장 길이·추론 부담을 매 단계 동시에 증가시킬 필요 없음.

- 긴 문장/전문어/높은 압축도는 해당 연령·L 안에서 상대적으로 구현.

- 고정 필자 4명은 비교 실험의 통제 조건일 뿐 서비스 생성 규칙 아님.

## 작성 순서 (최신 순방향 선정 계약과 정합)
1. **대분야 → 세부 분야 → 개별 주제 → 핵심 질문** 순서로 선정하고 단계별 이력을 기록. 이미 작성된 원고를 분류할 때의 역방향 검사와 구별.
2. 본문으로 수행할 **독해 목표 1~3개**를 설정하고 핵심 질문 및 필요한 사실 ID를 연결.
3. 사실·출처·용어·전제와 원문 근거의 확인 상태 점검. **정답에 필요한 지식은 본문 안에 제공**, 검증 전 자료는 검증 완료로 처리하지 않음.
4. 해당 연령·L의 관계·추론 부담 및 [연령별 비문학 지문 형식](AGE_GROUP_WRITING_AND_QUESTION_LANGUAGE_RULES_v1.md)을 확인.
5. 필자 **24개 속성 각각을 독립 균등 추출**하고 충돌 시 재추첨이 아니라 반영/부분반영/제한 및 이유 기록.
6. 정확성·독해 목표·논리를 우선해 자연스러운 원고 작성. 글자 수 강제 맞추기 금지.
7. 객관식 문항 및 **정답의 본문 근거 위치** 생성. 연령별 발문/문법·질문/보기 호응·사실/추정 표기 점검.
8. 품질 8영역과 [언어·사실 세부 검수 7항목](operations/quality/editorial_subchecks_v1.json), 중복/다양성 검수 후 부분 수정 시 다시 검수. **실제 사람 결과와 승인 구분**.

## 필수 검수
| 구분 | 합격 기준 |
|---|---|
| 사실성 | 확인 가능한 사실, 허위 수치·인용·단정 없음 |
| 독창성 | 외부 글의 표현을 베끼지 않음 |
| 본문 완결성 | 필수 용어·전제가 본문에 있음 |
| 연령 적합성 | 소재·어휘 접근성, 연령 편견/유아화 방지 |
| 난도 정합 | 해당 L의 관계·추론 부담 실현, 난도 역전 점검 |
| 문항 정합 | 독해 목표를 측정, 정답 근거 본문 내 존재 |
| 논리·자연스러움 | 억지 연결·불필요한 반복 없음 |
| 분량 | 실측 기록; 범위 이탈만으로 자동 불합격 아님 |
| 스타일 | 24속성 적용 로그와 충돌 조정 기록 |
| 다양성 | 최근 글의 주제·도입·전개·결말 반복 감시 |

검수 상태: `PASS`, `REVISE`, `REJECT`, `NEEDS_HUMAN_REVIEW`.
`PASS`는 내부 규칙 통과이며 **실제 학습자 난도 검증 통과가 아님**.
복수 정답/본문 밖 지식 요구 시 `REVISE`; 중요한 사실 검증 곤란 시 `NEEDS_HUMAN_REVIEW`.

## 자동화와 검증의 경계
- 규칙 검수: 분량 실측, 문항/근거 존재, 필자 속성 로그 완결성, 반복 주제 등.
- AI 보조 검수: 사실성·추론 단계·자연스러움·연령 적합성. 오류 가능성 관리.
- 실제 학습자 검증 필요: 정답률, 읽기 시간, 재검사 안정성, 학습 효과, 고령층 접근성.
- 원고 생성 규칙과 앱 구현은 별도 작업. 이 문서만으로 기능이 구현되었다고 보지 않는다.
