# 사실·근거 확보 규격 v1 — 3단계 중 ③

**상태: 출처/주장 연결 구조와 자동 검증 구현. 실제 원문 대조·사실 검증은 별도 작업.**

- 문장 단위 사실마다 고유 fact_id, 명시적 주장, 확인할 출처 source_id를 둔다.
- 출처에는 조직·제목·URL·확인 상태·검토자·점검일을 별도로 기록한다.
- 확인되지 않은 링크는 링크 자체가 존재해도 근거로 승인하지 않는다. 특정 구절/표/절 등의 locator를 실제로 확인하고, 사실별 검토자·날짜를 기록한 경우에만 검증 상태 변경이 가능하다.
- 출처 자체의 신뢰도, 주장의 진위, 시점에 따른 정보 변경, 이용 조건은 프로그램이 자동 확정할 수 없다. 관련 인력·AI 검수와 별도 운영 QA에서 다룬다.
- 객관식 정답에 필요한 사실은 해당 지문에 제공한다. 사실 ID와 독해 목표 ID의 연결은 자동 점검한다.
- **외부 자료는 사실 확인에 사용하되 기존 원문의 문장·고유 표현은 무단 복제하지 않는다.**
- P1 응결 실험의 URL 3개는 여기서 실제 원문을 다시 검증하지 않았으므로 source_check_status=NOT_CHECKED_IN_THIS_STAGE, 모든 사실은 PENDING_EXTERNAL_REVIEW로 기록했다. 허위 승인 방지 목적이다.
- 형식 검사 통과는 학습자 난도 검증이나 사실 참/거짓의 확정이 아니다. 배포 승인 플래그는 항상 별도로 관리한다.
