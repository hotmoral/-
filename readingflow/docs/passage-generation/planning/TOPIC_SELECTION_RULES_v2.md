# 비문학 주제 분류 적용 규격 v2

작성: 2026-11-20. 상태: **세부 분야 가변 분류안·기존 지문 30편 분류 검증 완료, 실제 주제 자동 배정 및 최종 승인 아님**.

## 요약
- **대분야 18개 / 세부 분야 298개(각 대분야 14~19개) / 개별 주제 무제한.**
- 초기 v1의 '대분야마다 세부 분야 4개'는 *임시 예시*이며 비례 또는 고정 제한이 아니다. v1은 이력 보존, 새 원고 분류 제안에는 **v2 사용**.
- 분야별 세부 항목은 각 분야의 성격에 따라 선정했다. 개수를 균등하게 할당하지 않았으며 향후 학문·사회 영역이 확장되면 분야와 세부 항목을 추가할 수 있다.
- **제작 순서:** 대분야 선정 → 세부 분야 선정 → 개별 주제 선정 → 핵심 질문 설정 → 독해 목표·사실 확보 → 필자 24속성 독립 추출. 주분야 1개·세부 분야 1개를 먼저 선택한다. **핵심 질문은 주제 선정 뒤 구체화·타당성을 점검하는 기준이며, 그 질문으로 주분야를 새로 추첨하거나 사후 바꾸지 않는다.** 보조 분야는 교차영역 기록용이다.
- 동일 대상이 여러 분야와 겹치더라도 주분야는 1개만 선정한다. 해당 판단이 애매하면 `NEEDS_EDITORIAL_REVIEW`로 보류한다.
- 분류표에서 빠진 새로운 분야를 발견하면 적절하지 않은 분류에 강제 투입하지 않고 `PROPOSED_NEW_SUBFIELD` 또는 `PROPOSED_NEW_DOMAIN` 상태로 등록하여 검토한다.
- 개별 주제의 개수와 글 제작 횟수에 상한은 없다. 단, 동일 소재·핵심 주장·독해 목표의 반복 여부는 별도 **중복·다양성 운영 체계**에서 확인한다.

## 검증 표본과 주의
- 기존 **30편 전부**를 읽기 전용으로 신규 분류표에 **잠정 매핑**했다.
- 그중 **13편**은 제목·기존 분야 정보만으로 주분야가 분명하지 않아 편집 재검토로 표시했다.
- 30편에 아직 등장하지 않은 주분야 5개: 정보·컴퓨터, 역사·고고학, 사회·문화, 경제·금융, 예술·디자인. **표본의 미사용 ≠ 주제 분류의 누락 또는 오류**.
- 학문 영역과 생활 응용 사이의 경계 **14개 사례**, 활용 범위 점검 **9개 주제군**을 별도로 기록했다.
- **298개라는 숫자는 이번 설계안의 목록 수일 뿐 분류 체계의 상한이나 사용 비중이 아니다.** 완전 포괄성은 실제 새로운 주제로 지속 검증해야 한다.

## 신규 원고 제작의 선정 절차 (확정 순서)
1. **대분야를 먼저 선정**한다. 분야별 특성·원고 편중·최근 사용 이력은 독립된 주제 편성 및 중복·다양성 관리 체계의 정보로 참고한다. 구체적 확률·균형 알고리즘은 별도로 설계한다.
2. 선정된 대분야 안에서 **세부 분야를 선정**한다. 분야별 세부 항목 수는 가변이며, 298개는 현재 제안 목록 수일 뿐 상한이 아니다.
3. 세부 분야에서 **개별 주제(설명할 현상·대상·사건)를 선택**한다. 개별 주제 수에 상한 없음.
4. 해당 개별 주제를 읽고 답을 찾을 수 있도록 **핵심 질문을 구체화**한다. 질문과 선정한 주제·분야가 맞지 않으면 '재검토'로 표시하고 **주제 선정 단계에 명시적으로 되돌아갈 수는 있지만**, 질문을 핑계로 주분야가 암묵적으로 변경되지는 않는다.
5. 필요할 때에만 보조 분야를 지정한다. 이는 **교차영역 관계를 기록하는 태그**이지 별도 원고를 중복 등록하거나 추가로 뽑는 단계가 아니다.
6. 독해 목표·사실·근거를 정한 다음 **필자 24개 속성에서 각각 독립 균등 무작위 추출**한다. 추출 이후 주제를 바꿔 스타일에 맞추지 않는다.

### 기존 원고를 분류할 때에만 역방향 검사
이미 원고가 있는 30편을 v2로 잠정 분류하는 작업에서는 **원고의 실제 내용과 핵심 질문을 먼저 읽고 어디에 속하는지 역으로 분류**할 수 있다. 이는 '기존 자료 정리'이며, 새 원고의 '분야부터 선정' 제작 순서와 다르다. 같은 규칙인 것처럼 취급하지 않는다.

## 기존 프로그램과 충돌 방지
- **원본 지문 30편, 저작권/근거 검증 정보, 필자 24속성·후보 172개, 난도/연령 기준**을 변경하지 않는다.
- 분류는 독해 학습 원고의 주제 탐색용이며 학술연구 통계 국제 분류와 동일하지 않다.
- 국제 분류를 참고한 자료: OECD FORD (Frascati) 및 UNESCO ISCED-F. 이 설계는 원고 사용을 위한 자체 분류안이며 국제 분류기관의 인증이나 완전한 매핑을 주장하지 않는다.
