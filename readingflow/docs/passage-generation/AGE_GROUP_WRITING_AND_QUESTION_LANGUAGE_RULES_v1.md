# 연령군별 비문학 원고 형식·발문 언어 규칙 v1

> **신규 제작 최신 기준 (2026-11-22):** [NEW_PASSAGE_AUTHORING_AND_MCQ_CANONICAL_2026-11-22.md](NEW_PASSAGE_AUTHORING_AND_MCQ_CANONICAL_2026-11-22.md). 지문 밖 배경지식으로 정답을 추측할 수 있다는 점은 결함이 아니다. 정답에 필요한 정의·조건·근거는 지문 안에 있어야 한다. 기존 문항의 답안 고정 규칙과 신규 문항 초안 작성의 권한을 구별한다.

**성격:** 이전 대화(2026-11-14/17/18)에서 명시된 합의를 복원하여 통합 제작 규칙에 연결한 문서. **기존 30편·90문항 수정 지시가 아니다.** 과거 대화 전체 원문 전수 확보가 아니므로 누락 감사와 함께 사용한다.

## 1. 적용과 불변 원칙

- 학습 지문은 **사실 기반 자체 창작 비문학 100%**. 외부 자료는 사실 확인·교육적 문체 관습 참고에만 사용; 출처의 독창적 표현/구성을 무단 복제하지 않는다.
- 5개 연령군 × 각 L1~L6. 연령군은 **지문의 주된 형식, 문장 접근성, 익숙한 개념의 맥락**을 고르는 기준이지 사고 능력 상한이 아니다.
- **주제·독해 목표·사실 확보 → 24개 필자 속성의 독립 무작위 추출 → 원고 작성**. 연령에 맞춰 필자 선택 확률을 임의로 가중하거나 재추첨하지 않는다. 선택된 문체를 연령·난도·사실성의 범위에서 적용한다.
- 내용 난도는 관계 수·근거 분산·추론 거리·조건/예외·판단 부담으로 조정하며 글자 수와 독립. 분량을 맞추기 위한 억지 반복·불필요한 문단 삽입·중요 근거 삭제 금지.
- 다음 표의 형식은 **중심 지향**이지 연령군에서 허용하는 비문학을 획일적으로 제한하는 배타적 장르 분류가 아니다.

## 1-A. 본문 공통 서술체와 질문 문체는 서로 다른 규칙 (2026-11-14·18 확정 내용 복원)

- **본문 원고 공통 기본 서술체는 평서형 문어체 `~다 / ~이다 / ~한다`**. 연령군에 따라 달라지는 것은 형식·설명 깊이·전개·어휘·추론 부담이지, 모든 독자에게 친절하게 보이려는 이유로 본문 전체를 `~습니다`로 바꾸는 것이 아니다.
- 글 안의 **인용 대사나 의도적인 질문**은 문장 기능에 맞게 자연스럽게 쓰되, 전체 원고의 기본 서술체가 무너지는지 확인한다. 직접 인용/의문문 한 줄만을 보고 자동 결함 판정하지 않는다.
- **독해 문항 발문은 본문 문체와 별개**다. 문제집·교과서·학습지의 실제 표현을 참고하여 연령군별로 자연스러운 문체를 사용하고, **동일 연령군 안에서는 일관성을 유지**한다. 2026-11-18 추가 합의에 따라 **‘글에 따르면’은 필요한 문항에만** 사용하며 일괄적으로 반복하지 않는다.
- 이번 원고 30편의 `~다`/ `~습니다` 혼재 여부는 이전 작성본의 **읽기 전용 검토 대상**이며, 본 기준을 이유로 원본을 덮어쓰지 않는다.

## 2. 연령군별 비문학 원고의 기본 방향 (기존 합의 복원)

| 연령군 | 주된 원고 형태와 설명의 방향 | 문항 발문에서 확인할 점 |
| --- | --- | --- |
| **초등 저학년** | 어린이 교양·현대 생활·학교·자연·동물의 관찰형/기초 설명문. 구체적인 대상을 설명하되 단순한 암기 글만 양산하지 않음 | 질문 대상을 선명하게 하고 **완결된 질문 문장** 사용. 문장 자체를 해석하는 데 불필요한 부담을 주지 않음 |
| **초등 고학년** | 교과 연계 탐구·현상의 원리·비교·조건을 확인하는 설명문 | 사실 확인만 반복하지 않고 원인·조건·근거를 묻는 문항을 구성. 실제 교과서/학습지에서 자연스럽게 사용하는 어휘·문장 호응 참고 |
| **중·고등학생** | **수능 국어 독서형 비문학이 주력**. 개념·원리·관계·추론·논리 전개·자료 해석을 다룰 수 있음 | 시험형 독해 발문의 정확한 논리 범위와 정답 유일성 점검. '수능처럼 보이게 하려고' 비문·과잉 복잡문을 만들지 않음 |
| **성인** | 전문 교양·분석적 해설·심화 정보, 필요할 때 LEET식의 논증·추론 부담 참고 | 분석/비교/평가를 요구하되 필요 이상의 생략형·어색한 질문을 만들지 않음. 전문 배경지식이 정답의 필수 조건이 되지 않도록 본문 내 근거 제공 |
| **고령층** | 시사·교양 해설, 생활·공공정보 등 활용성이 있는 비문학을 포함 | 가독성·문장 명확성·정보 제시 부담을 살피되 **사고력이나 고차 추론을 연령만으로 제한하지 않음**. 일률적 유아화 금지 |

이 형식은 원고 기획 단계의 기준이다. 종합 난도 L1~L6의 상대적 차이는 같은 연령군 안에서도 별도로 적용하며, '저학년에게 쉬운 질문만' 등으로 독해 목표를 고정하지 않는다.

## 3. 문항 제작 시 발문 언어 검수 — 과거 누락 사항의 복원

1. **시중 교재의 실제 관습 참고:** 초등 교과서·학습지·문제집, 중·고등 독서 평가 등 **해당 연령에 맞는 발문 관습**과 어휘·형식·맥락을 참고한다. 단 특정 교재의 문항을 그대로 복제하지 않는다.
2. **자연스러운 완결문:** 문장 성분·조사·시제·서술어 호응이 성립하고 **종결 어미를 갖춘 완결된 질문 문장**을 우선 사용한다. '문제집 같은 말투'라는 이유로 부자연스러운 생략형이나 단문 단편을 반복하지 않는다.
3. **질문·보기 연결:** 질문에서 요구하는 대상, 시간, 수량, 원인, 비교 기준, 추론 범위가 선택지와 문법적·의미적으로 정확히 호응하는지 검사한다.
4. **중의성 검사:** 한 질문에 복수의 합리적 해석이 생기지 않는지, 정답 후보가 둘 이상 가능한지 별도로 확인한다.
5. **정답의 본문 근거와 보기 표현:** 정답에 필요한 정의·조건·근거는 지문 안에 있어야 한다. **배경지식으로 지문 없이도 정답을 추측할 수 있다는 이유만으로 문항을 수정하거나 감점하지 않는다**(2026-11-22 확정). 정답만 지나치게 짧거나 길고 오답에만 단정형 표현이 몰린 것처럼 **문항 자체의 표면 힌트**는 점검한다. 정답 유일성·안전성을 위해 다소 쉽게 구분되는 오답도 허용한다.
6. **연령·L 적합성:** 질문의 언어 난도와 지문이 요구하는 실제 사고 난도를 구별한다. 비문이나 과도한 문장 길이로 어려움을 높이지 않는다.
7. **같은 지문 내 중복:** 3~6문항의 정보 근거, 논리 관계, 답변 대상이 실질적으로 중복되는지 확인한다. 질문의 유형 이름만 다른 것은 다양성으로 인정하지 않는다.
8. **검수 단계 분리:** 사람이 하는 ① 지문 미제시 답 노출 검수와 ② 지문 제시 정답 유일성·근거 검수를 구별한다. 자동 검사와 AI 판정은 사람 검수/학습자 성과로 포장하지 않는다.

> **주의:** 문법적으로 허용되는 통상적인 시험형 축약 발문을 자동으로 모두 비문이라고 선언하지 않는다. 하지만 과거 사용자 요청의 *완결된 질문 종결* 기준과 맞는지는 별도 점검한다. 실제 문제집의 형태를 그대로 가져오면 된다는 뜻도 아니다.

## 4. 비문학 내용의 정확성과 논리

- **사실·추정·가설·의견**을 혼동하지 않고 확실성 수준이 내용과 일치하는지 확인한다. 필요한 정의·전제·근거를 본문에 제공한다.
- 상관과 인과를 혼동하거나 관찰만으로 단정하지 않는다. 수치·인용·통계·출처가 불명확하면 창작하거나 참이라고 처리하지 않는다.
- 사실/근거 검증 상태의 데이터 필드 존재와 실제 출처 본문 검증 완료는 별도다. 본문과 문항 모두 이를 준수한다.
- **본문을 읽었을 때 정답을 결정할 충분한 근거가 있고 정답은 하나**여야 한다. 배경지식으로 이미 답을 추측할 수 있는지는 품질 판정에서 제외한다. 오답 설득력을 높이다 복수 정답을 만들면 안 된다.

## 5. 현재 R4 원본 보존과 앞으로 새 문항 제작의 구별

- **기존 R4 90문항**: 현행 작업 범위는 오답 변경뿐. 원본 질문·정답 문구·위치·원고를 이번 복원 작업으로 덮어쓰지 않는다. 문장 불완전/비문·질문-정답 범위 오류는 별도 검수 기록으로 남긴다.
- **신규 문항 제작**: 애초에 완성된 자연스러운 질문을 작성하며, 표현 문제를 발견하면 정답·근거·선지 재검수 절차에 따라 작성 단계에서 수정할 수 있다.
- 실제 검수자와 학습자 자료가 확보되지 않았으므로 **배포 승인/실측 난도 완료 선언 금지**.
