# Linkline A3 target-pair diversity — public execution approval

Approval date: 2026-10-27
Approved by: project owner in ChatGPT session

## Approved work unit

Run deterministic public computation needed to expand N5/N6 candidate supply for
the 1,300-stage target-pair diversity replacement campaign.

The intended campaign policy is:

- N3/N4: an exact board-coordinate target pair may be used at most once.
- N5/N6: an exact board-coordinate target pair may be used at most twice.
- Launch total remains 1,300.
- Existing mechanic, solver, structural-feature, research-identity, and private
  isolation contracts are not changed by this public work unit.

## Public surfaces explicitly allowed

- deterministic generation/sampling configuration and state-count bounds;
- existing already-public mechanic/solver/structural-analysis source projections;
- deterministic execution parameters and domain matrix;
- de-identified research-equivalence IDs;
- structural/signature metadata and aggregate fingerprints/summaries;
- public-safe generated candidate artifacts needed for private canonical closure.

## Not approved for public exposure

- private canonical documents or private repository contents;
- private isolation IDs/lists;
- human-participant exports, self-test exports, telemetry, or user data;
- secrets, credentials, tokens, or private environment values;
- raw private source/evidence files.

## Additional minimization used by this run

Although candidate geometry is not needed to be secret for the computation, this
run deliberately does **not** emit initial paths or target coordinates. Geometry
will be deterministically reconstructed in the private canonical lane before the
exact target-pair capacity audit and final selection.

This approval applies only to the target-pair candidate acquisition work unit.
